Use `/Users/parthpatel/endless_runner/.agent/` as a scratchpad for plans and todo lists.

## First run
Initialize the Vite + Excalibur project, then write `.agent/todo.md` listing all tasks.

## Requirements
- Auto-running player with jump
- Procedural obstacle spawning
- Increasing speed over time
- Score tracking and game-over/restart screen
- All tunable values in a single `config.ts`

## Time allocation
- 70% core gameplay
- 20% polish (parallax background, screenshake, audio)
- 10% tests (spawning logic, collision detection)

When all tasks are done, write "DONE" to `.agent/status.md`.

Make decisions autonomously. Do not ask clarifying questions — pick the most reasonable option and proceed.

If you are unsure about anything, write your assumption to .agent/notes.md and continue.
Never wait for confirmation. If a task is blocked, skip it and move to the next one.
